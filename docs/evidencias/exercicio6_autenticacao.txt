## 1. Cadastro público sempre cria paciente
$ curl -s -X POST http://127.0.0.1:8000/usuarios -H 'Content-Type: application/json' -d '{"username":"maria","nome":"Maria Souza","password":"senha-forte-123"}'
{"username":"maria","nome":"Maria Souza","papel":"paciente"}  → HTTP 201
(joao cadastrado do mesmo jeito)
$ curl ... -d '{"username":"intruso","nome":"X","password":"senha-forte-123","papel":"administrador"}'
{"detail":[{"type":"extra_forbidden","loc":["body","papel"],"msg":"Extra inputs are not permitted","input":"administrador"}]}  → HTTP 422

{"username":"dra.ana","nome":"Dra. Ana Costa","papel":"profissional"}  → HTTP 201

{"username":"dr.paulo","nome":"Dr. Paulo Lima","papel":"profissional"}  → HTTP 201

## 7. Consultas com ownership
$ curl -s -X POST http://127.0.0.1:8000/consultas -H 'Authorization: Bearer <dra.ana>' -d '{"paciente":"maria","especialidade":"Cardiologia","data_hora":"2026-10-06T10:00:00","motivo":"Dor no peito ao esforço"}'
{"id":1,"paciente":"Maria Souza","profissional":"Dra. Ana Costa","especialidade":"Cardiologia","data_hora":"2026-10-06T10:00:00","motivo":"Dor no peito ao esforço","status":"agendada"}  → HTTP 201
$ (paciente tentando criar consulta)
{"detail":"Escopo insuficiente para esta operação"}  → HTTP 403
$ curl -s http://127.0.0.1:8000/consultas/1 -H 'Authorization: Bearer <maria, dona>'
